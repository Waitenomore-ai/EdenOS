## Implemented remote-only work

### Boot and branding

- Eden Plymouth wallpaper and centred logo during normal boot.
- Quiet `splash` boot defaults.
- Basic-graphics/recovery path using `nomodeset`.
- BIOS and UEFI catalogue checks plus amd64 EFI-header inspection in the ISO
  pipeline.
- The physical iMac firmware chime is not changed by EdenOS; it happens before
  Linux starts.

### Magical startup sound

- Original magical fairy/butterfly WAV packaged at:
  `/usr/share/sounds/edenos/startup.wav`
- LightDM starts it once when the login screen is prepared.
- `nomodeset` recovery boots remain silent.
- To mute it on an installed system, create:
  `/etc/eden-os/startup-sound.disabled`
- The wrapper fails quietly if ALSA or the sound file is unavailable, so login
  is not blocked by audio problems.

### Child profiles

Implemented source models:

- Validated profile cards with built-in avatars only.
- Private local profile store with atomic writes and duplicate rejection.
- Side-effect-free adult profile editor model.
- Side-effect-free child profile chooser model.
- Public greeter data contains display name and avatar only; usernames remain
  internal account mappings.
- Invalid selections clear safely.
- Text-login fallback remains available.

The chooser is not yet connected to the real LightDM greeter. That integration
must be tested in a graphical installed system before enabling it.

### Accessibility

- Text scaling from 100% to 160%.
- High-contrast mode.
- Reduced-motion preference.
- Explicit keyboard focus styling.
- GTK accessibility labels on launcher controls.
- Accessibility settings saved locally in a private `0700` directory.
- Preference file permissions are `0600`.
- Reduced-motion now applies a CSS class that disables transitions and
  animations.

### Backup and recovery

- `eden-backup` creates private timestamped archives.
- Existing destination is required; archives are never overwritten.
- Eden work folders and `.config/eden-os` are included.
- `.cache` is excluded.
- The completed tar archive is tested before it is published.
- This is a convenience backup, not a complete disk image or automatic rollback
  system.

## Installing the update on the existing iMac

Use the update artifact first; it does not repartition the disk.

1. Boot the iMac using the working basic-graphics entry.
2. Log in as `edenadmin`.
3. Download the update artifact and extract the ZIP.
4. Keep the `.deb` and `eden-os-update.sha256` together.
5. Verify the package:

   ```sh
   sha256sum -c eden-os-update.sha256
   ```

6. Install the exact package filename:

   ```sh
   sudo apt update
   sudo apt install ./eden-os-desktop_VERSION_all.deb
   ```

7. Log out and back in.
8. Test Eden Home, accessibility settings, the startup sound, backup command,
   and basic-graphics recovery.

Do not erase or repartition the SSD for an update. Keep the previous package
and a backup available.

## Creating a USB installer

1. Download the ISO artifact ZIP on Windows.
2. Extract the ISO.
3. Verify its SHA-256 against the build checksum.
4. Write the ISO to a USB stick with a trusted image writer such as Rufus or
   balenaEtcher.
5. Safely eject the USB and boot the iMac using its boot picker.

The ISO is installation/live-test media. It does not automatically update an
existing installed system.
