# The Little Bee's Busy Day — artwork staging

Book 23 in the 75-book Story Garden library (`the-little-bee-s-busy-day`).

Five sequential page illustrations (`page-01.png` through `page-05.png`), 1920 × 1080, fully opaque RGB PNG.

Story focus: Eden and Priya help one little bee find lavender, by carefully observing and following purple flowers. Both children must be composited later from their separately approved portraits, with the right-hand ~45% of the illustrated page available for their placement.

No story text is embedded in the artwork. No child avatars are embedded. This is an artwork-only staging pack, not a deployment or permission to overwrite approved existing work.
